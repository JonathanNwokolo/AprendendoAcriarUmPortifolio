# 🌟 Portfólio Dev Club

Este projeto é um site de portfólio pessoal desenvolvido acompanhando o tutorial do **Rodolfo Mori** do **Dev Club** em um de seus vídeos.

## 📋 Sobre o Projeto

Um site responsivo de portfólio pessoal com design moderno e elegante, ideal para desenvolvedores apresentarem seus projetos e habilidades.

## 🚀 Funcionalidades

- **Navegação Suave**: Menu com scroll suave entre as seções
- **Seção Inicial**: Apresentação com foto de perfil e título
- **Sobre Mim**: Espaço para descrição pessoal e profissional
- **Meus Projetos**: Galeria de projetos desenvolvidos
- **Contato**: Seção para informações de contato

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Design Responsivo
- Variáveis CSS

## 🎨 Características do Design

- Tema escuro moderno
- Efeito glassmorphism (vidro)
- Paleta de cores personalizada com roxo e índigo
- Layout responsivo
- Animações e transições suaves

## 📁 Estrutura de Arquivos

```
├── index.html          # Estrutura principal do site
├── style.css           # Estilos e design
├── img/               # Pasta de imagens
└── README.md          # Este arquivo
```
